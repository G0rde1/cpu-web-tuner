# 🚀 CPU Web Tuner - Полноценный веб-мониторинг CPU

**CPU Web Tuner** - это профессиональный веб-интерфейс для мониторинга и управления CPU в реальном времени.

## ✨ Возможности

- 📊 **Веб-интерфейс** с графиками в реальном времени
- 🌡️ **Мониторинг температур** всех ядер CPU
- ⚡ **Управление частотами** и governor'ами
- 📈 **Графики загрузки** CPU и памяти
- 📝 **Логирование** всех параметров
- 🐳 **Поддержка Docker**
- 🔧 **Автозапуск** через systemd
- 📱 **Адаптивный дизайн**

## 📦 Установка

git clone https://github.com/rfg3rwe/cpu-web-tuner.git
